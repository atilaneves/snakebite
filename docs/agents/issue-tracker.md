# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues. Use the
`gh` CLI for all operations. Infer the repository from the Git remote.

Pull requests are not a request surface.

When a skill says to publish to the issue tracker, create a GitHub issue. When
a skill says to fetch a ticket, read the full issue and its comments.

Use GitHub native sub-issue and blocking relationships when available. If issue
dependencies are unavailable, record blockers in the issue body.
