# Domain docs

This repository uses a single-context domain-document layout.

Before work, read `CONTEXT.md` and relevant records in `docs/adr/` when they
exist. If they do not exist, continue without comment. Domain-modeling work
creates them only when the project resolves relevant terms or decisions.

Use terms from `CONTEXT.md` in issues, tests, proposals, and documentation.
Report conflicts with an existing ADR instead of silently overriding it.
